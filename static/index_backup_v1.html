Warehouse Architecture: Local SQL vs API

Design Resolution:


  • Rate Limit Protection: Massive/Polygon Basic plans restrict queries to 5 calls/min. Querying live API on every backtest loop causes 429 errors.
  • Sub-Millisecond Speed: SQLite queries in data/warehouse.db run in 0.3ms vs 350ms+ over the web.
  • Clean Historical Alignment: The SQL warehouse synchronizes trading dates across multiple assets automatically, enabling continuous rolling regression without calendar gaps.
